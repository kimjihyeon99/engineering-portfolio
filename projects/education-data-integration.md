# AI 디지털교과서(AIDT)

**기간:** 2024.03–2025.06  
**역할:** Software Engineer / Full-stack 개발 및 운영  
**주요 기술:** Java, Spring Boot, Spring Batch, MyBatis, Feign Client, React, TypeScript, MySQL, Redis

## 프로젝트 개요
학생 개인의 능력과 수준에 맞는 다양한 학습 기회를 지원하기 위해 인공지능을 포함한 지능정보기술을 활용하고, 다양한 학습자료와 학습 지원 기능을 제공하는 AI 디지털교과서 서비스입니다.

서비스 구축 단계부터 오픈 이후 운영까지 참여했습니다.

## 개발 경험

- 운영자(Admin) 기능 개발
- 외부 콘텐츠·API 연계 및 오류 처리

## 대표 의사결정. 외부 API 데이터 사전 적재와 정합성 보장
### 문제
사용자 요청 시 특일 정보 외부 API를 직접 호출하면 Timeout이나 일시적인 장애가 사용자 요청에 그대로 영향을 줄 수 있었습니다. 또한 데이터 갱신 실패 과정에서 기존 정상 데이터가 유실되지 않아야 했습니다.

### 직접 설계한 구조
서비스에 필요한 **당월·익월 데이터를 Spring Batch로 사전 수집해 DB에 적재**하도록 설계했습니다.

사용자 조회는 외부 API가 아닌 내부 DB 데이터를 기준으로 처리해 외부 시스템 장애가 사용자 요청에 직접 전파되지 않도록 했습니다.

### 데이터 정합성 처리
1. 외부 API 데이터를 먼저 수집합니다.
2. 수집이 성공한 경우에만 기존 대상 데이터를 삭제하고 신규 데이터를 INSERT합니다.
3. 삭제와 적재를 **하나의 DB Transaction**으로 처리합니다.
4. 저장 중 실패하면 Rollback해 기존 정상 데이터를 유지합니다.
5. 외부 API 수집 자체가 실패하면 기존 데이터를 그대로 유지하고 다음 Batch에서 다시 시도합니다.

Feign 호출에는 Timeout과 Retry를 적용해 일시적인 연동 오류도 대응했습니다.

### 의사결정 기준
- **데이터 정합성:** 실패 과정에서 정상 데이터가 유실되지 않을 것
- **서비스 안정성:** 외부 API 장애가 사용자 조회에 직접 영향을 주지 않을 것
- **가용성:** 최신 데이터 수집에 실패하더라도 마지막 정상 데이터를 제공할 것

대신 데이터 최신성은 Batch 주기에 종속되는 Trade-off가 있습니다.

## 운영 경험
서비스 오픈 이후 사용자 문의, 외부 API 오류, 데이터 이슈, 캐시 및 메시징 관련 문제를 분석하고 개선했습니다. EFK 로그를 통해 요청 흐름과 오류 지점을 추적하고 원인을 확인했습니다.
